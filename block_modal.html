Audio Mixer

{{ node_title }}

Combines sources into one new Ogg/Opus stream. Stopping one source leaves the others playing. Mute/gain are applied at the next Run.

Sources

Connect both ports of each producer. Sources 1 and 2 are permanent; added sources can be removed once disconnected.

Outputs

audio_outcommand_out

Opus · 48 kHz · audio + explicit commands

Arrival-aligned live mixing, not studio sample synchronization. Two seconds of decoded buffering per stream; a limiter prevents PCM overload. This is not echo cancellation.

Advanced settings

Up to 16 simultaneous streams. Final-frame timeout is a safety limit, not a delay added to every stream.

Changes remain local until Apply. Stop, then Run to activate saved settings; these are not live volume controls.
